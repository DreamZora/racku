# Decision: License the project under MIT

Status: accepted

## Background

- The initial commit of the repository used AGPL-3.0.
- rack42u is a base framework for other people to build applications. Under AGPL, an application that provides a network service based on it usually must also publish its source code, so many companies ban AGPL libraries outright. That would shut the framework's main users out.

## Decision

- The repository license changes to MIT, with the copyright notice `Copyright (c) 2026 Zora`.
- Newly introduced third-party code and dependencies must carry a license compatible with MIT.

## Alternatives

- **Keep AGPL-3.0**: enterprise users would find it hard to adopt, which conflicts with the positioning of the framework.
- **Apache-2.0, MPL-2.0**: these were listed as candidates alongside MIT during the discussion, and the user ultimately chose MIT.

## Impact

- Anyone may use, modify, and distribute rack42u in closed-source or commercial projects, as long as the copyright notice and the license notice are kept.
- The license no longer forces changes to be contributed back, so improvements others make to the framework do not necessarily return to this project.
- Licenses must be checked when adding dependencies: GPL- and AGPL-type dependencies would change the distribution terms of the whole project and require a separate decision.
